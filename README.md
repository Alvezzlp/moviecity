# 🎬 Landing Page de Filmes

Uma landing page moderna, responsiva e interativa desenvolvida para apresentar lançamentos, destaques e novidades do mundo do cinema.

---

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estruturação semântica da página.
- **CSS3**: Estilização, layout responsivo (Flexbox/Grid) e animações.
- **JavaScript (ES6+)**: Interatividade, manipulação do DOM e dinamicidade dos conteúdos.

---

## 💻 Como Executar o Projeto

Podes executar este projeto no teu computador de forma simples seguindo os passos abaixo:

### Pré-requisitos
Apenas precisas de um navegador web atualizado (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari, etc.). Opcionalmente, podes usar um editor de código como o VS Code.

### Opção 1: Execução Direta (Sem instalação)
1. Faz o download ou clona este repositório para o teu computador.
2. Navega até à pasta do projeto.
3. Dá duplo clique no ficheiro index.html (ou clica com o botão direito e seleciona "Abrir com" > teu navegador preferido).

### Opção 2: Utilizando o VS Code (Live Server)
1. Abre o VS Code.
2. Abre a pasta do projeto através do menu Ficheiro > Abrir Pasta...
3. Instala a extensão Live Server (caso ainda não a tenhas).
4. Clica com o botão direito no ficheiro index.html e seleciona "Open with Live Server".
5. O projeto será aberto automaticamente no teu navegador com atualização em tempo real (hot-reload).

### Opção 3: Passos para Abrir via Terminal/Linha de Comandos
1. Clona o repositório com o comando: git clone https://github.com/teu-utilizador/landing-page-filmes.git
2. Entra na pasta do projeto: cd landing-page-filmes
3. Abre o ficheiro index.html no teu navegador.

## 📂 Estrutura de Imagens e Ficheiros do Projeto

As imagens e recursos visuais utilizados no projeto devem ser organizados no diretório assets/images/ (ou images/):

.
├── assets/
│   └── images/
│       ├── banner-principal.jpg    # Imagem de destaque do filme principal (Hero Section)
│       ├── card-filme-1.jpg        # Poster do filme 1
│       ├── card-filme-2.jpg        # Poster do filme 2
│       ├── card-filme-3.jpg        # Poster do filme 3
│       ├── logo.png                # Logótipo do site
│       └── favicon.ico             # Ícone do separador do navegador
├── index.html                      # Ficheiro HTML principal
├── styles.css                      # Ficheiro de estilos CSS
└── script.js                       # Ficheiro de interatividade JavaScript
